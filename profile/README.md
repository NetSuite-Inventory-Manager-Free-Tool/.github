## 📌 About the Tool
**NetSuite Inventory Manager** is a Windows-based companion app for managing NetSuite inventory data. It provides direct, secure access to stock information, adjustments, and transaction records for efficient warehouse and ERP operations.

## ❓ What is NetSuite Inventory Manager?
This utility integrates with NetSuite’s API endpoints to let you review stock levels, update item quantities, and synchronize adjustments without opening the browser interface. It’s ideal for warehouse teams, accountants, and purchasing managers working in real time.

## ✅ Why Choose NetSuite Inventory Manager?
- Quick access to NetSuite inventory data  
- Real-time synchronization of stock and item lists  
- Faster workflows for updates and adjustments  
- Lightweight desktop interface  
- Secure authentication with user roles and tokens  
- Compatible with standard NetSuite ERP environments  
- Designed for warehouse and purchasing departments  

## 🔧 Key Features
- Real-time view of item quantities and locations  
- Manual and automated stock adjustments  
- Inventory transfer and fulfillment entry  
- Export reports to CSV or Excel formats  
- Secure OAuth or token-based NetSuite login  
- Offline mode with cached synchronization  
- Customizable filters for categories and warehouses  
- User activity logging and audit trail  

---

## 🖥️ System Requirements
- Windows 10/11 (64-bit)  
- Internet connection for NetSuite API access  
- .NET 6.0 Runtime (or higher)  
- 200 MB free disk space  
- Administrator privileges for installation  

## ▶️ Usage
1. Launch **NetSuite Inventory Manager**.  
2. Sign in using your NetSuite credentials or integration token.  
3. Sync your current item list and stock data.  
4. Adjust, transfer, or export records as needed.  
5. Log out securely after updates.
